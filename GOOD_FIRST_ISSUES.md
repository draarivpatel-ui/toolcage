# Good first issues

These are scoped contributions suitable for a first pull request after launch.

1. Add a documentation recipe for wrapping one common MCP server tool shape.
2. Add additional deterministic SSRF fixtures for unusual public IPv6 forms.
3. Improve README examples for command tools that use argument arrays instead of shell strings.
4. Add tests for policy-audit warnings on newly introduced escape hatches.
5. Add a small benchmark script that measures validation throughput without adding dependencies.
6. Review error messages for clarity while preserving stable error codes.
7. Add a threat-model diagram using plain text or SVG with no external assets.
8. Add Windows-specific path traversal tests that do not depend on a Windows machine.

Before claiming one, open or comment on the issue so work is not duplicated.
